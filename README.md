Proyectos de datos · Gonzalo Escribano

Estudiante de Ciencia de Datos en Organizaciones (UNLP). Este repositorio reúne tres proyectos en Python y SQL (SQLite) sobre modelado de bases de datos, limpieza de datos y análisis.

#	Proyecto	Qué demuestra	Stack
03	Sistema de ventas a pedido	Base relacional de 3 tablas, carga de pedidos y 5 gráficos de análisis	Python, SQLite3, SQL, Matplotlib
02	Análisis de rendimiento de centrales (FM24)	Limpieza con Pandas, base SQLite y ranking calidad/sueldo	Python, Pandas, SQLite3, SQL
01	Armador de PC con validación de compatibilidad	Modelo relacional de 4 tablas y reglas de compatibilidad	Python, SQLite3, SQL
Cómo correr cualquier proyecto
bash
git clone https://github.com/GonzaloEscribano/Proyectos.git
cd Proyectos/<carpeta-del-proyecto>
pip install pandas numpy matplotlib   # solo lo que use cada proyecto

Cada carpeta tiene su propio README con los pasos exactos.
